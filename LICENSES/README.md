Files in data/raw/ are the exact local workbooks/README used by the study; checksums record these analysis inputs. No claim is made that a fresh online download is byte-identical. The historical workbook contains 980 candidate identifiers although its landing-page description says 956. Neither mismatch is resolved by guessing a version change. Compiler geometry/conversion claims are not independently confirmed for every row.

Derived tables add source mappings, eligibility flags, source–recipe groups, splits and predictions; changes are described in reproducibility/DATA_LINEAGE.md. The main strength analysis retains all 1,736 records, including compiler outlier flags; it does not follow the upstream recommendation to exclude them. No new experimental measurements are introduced.
