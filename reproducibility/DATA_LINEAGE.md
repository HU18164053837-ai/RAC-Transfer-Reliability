# From source workbooks to modelling matrices

1. prepare.py reads the new strength/slump workbooks and restores publication references only inside actual merged cells in source column B. The compiler README's 119 reference entries provide source identities. Constituent/property columns are renamed and kept in their original documented units. All 1,736 strength records and the original outlier flag are retained; the flag never becomes a predictor. No new strength/age/geometry conversion occurs.
2. data/raw/legacy supplies the actual historical workbook, all-candidate classification, existing 722-row modelling subset and bibliographic corrections. prepare.py creates data/derived/old_modeling_copy.csv and old_raw_980_copy.csv. Its eligibility/scope fields retain the distinctions between 980 candidates, 722 frozen records and the 586-row six-input stress cohort.
3. experiment.py contains the actual Phase 1 grouping algorithm: source identities and target-free near-recipe links form components. Frozen outputs results/new_groups.csv and new_recipe_edges.csv describe the 99 main components; transfer_groups.csv and transfer_exclusion_ledger.csv record historical stress-test associations and exclusions. Inputs are not grouped using observed prediction errors.
4. phase2/prepare_phase2.py verifies all known recipe links, constructs phase2/data/new_frozen.csv, metadata-risk flags, duplicate-sensitivity flags and label/source ledgers. Source identity consolidates DB2/DB75. Aggregate-property equality is not required for the recipe link. Seven priority source-row mappings remain unknown, not corrected on model error.
5. phase2/run_experiments.py contains the actual fixed ExtraTrees, grouped out-of-fold scale model, residual/source-balanced/adaptive/group-maximum calibration and selection scores. Splits are stored in phase2/results/split_ledger.csv; within-scale folds are in scale_training_oof.csv. Calibration/test labels do not order rejections. Main rows occur once per repeat; two repeats are dependent.
6. phase2/analyze.py and phase3/supplement.py contain the actual metric, group bootstrap, interval-score and service-scope calculations. Frozen bootstrap intervals are retained; repository checks do not rerun resampling. Successful service uses original denominators and is not an engineering safety probability.
7. phase4/source_data/ and tables/ are the v0.2 plotting/table inputs. Frozen figures/ are unchanged. phase4/plot_figures.py regenerates Figs. 2–5/S1, while plot_fig1_v02.py restores the v0.2 Figure 1 presentation. All generated outputs go to reproduced/figures by default.

The stage directories are deliberately retained. Portable packaging changes only paths/shared-input references and output destinations; checksums/code_adaptations.csv identifies every adapted script. checksums/origin_map.csv identifies unchanged scientific inputs/results. Shared files are not recopied: phase2/common.py and phase3/common.py expose explicit INPUT_PATHS maps and data_file(name). supplementary/electronic_file_index.csv maps each original SI CSV to one canonical repository file and its frozen hash.

The data/legacy_context/ directory contains only necessary audit context already used by the second study. It is not a migration of the historical research project. Re-running preparation/training can overwrite a working clone's stored outputs; perform such work only in a disposable copy. No original workspace path or first-paper repository is required for the saved-prediction checks.
